## 2024-03-24 - CSV Injection (Formula Injection) Vulnerability
**Vulnerability:** The `Monitor.log_trade` method writes user-provided strings (like the `comment` field) directly to a CSV file without sanitization. Strings starting with `=`, `+`, `-`, or `@` can be interpreted as formulas if the CSV is opened in spreadsheet software like Microsoft Excel or LibreOffice Calc, leading to potential CSV Injection (Formula Injection).
**Learning:** Even internal logging mechanisms like trade logs that are exported to CSV need input sanitization. A malicious actor, or even benign data containing specific prefixes, could cause unintended execution of formulas or data exfiltration when the file is viewed. Purely numeric strings (like `'-150.50'`) might start with `-` but should not be escaped to avoid downstream data corruption.
**Prevention:** Always sanitize strings written to CSV files by prepending a single quote (`'`) to values starting with `=`, `+`, `-`, or `@`, unless they represent valid numeric values that shouldn't be altered.
