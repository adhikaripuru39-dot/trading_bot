## 2024-10-06 - [CSV Injection Vulnerability in Monitor Logging]
**Vulnerability:** The trading bot's `log_trade` method logged unsanitized fields directly into a CSV file. If variables like `comment` or `symbol` contained characters such as `=`, `+`, `-`, or `@` at the beginning, they could be treated as formulas when opened in spreadsheet software like Excel, executing malicious code.
**Learning:** This vulnerability existed because the CSV writer assumed all data coming from internal systems or arguments was safe to format as plain text. However, dynamically generated content, such as a trade comment, could be controlled or influenced by external inputs or data processing layers, resulting in unintended formula execution.
**Prevention:** Always sanitize input fields before writing them to CSV by prepending a single quote (`'`) to strings that start with `=`, `+`, `-`, or `@`. Care must be taken not to sanitize pure numeric strings (like `-150.50`) to avoid disrupting intended data formats.
