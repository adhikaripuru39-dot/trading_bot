## 2024-05-24 - CSV Injection (Formula Injection) in Trade Log Monitor
**Vulnerability:** The trade logging system (`monitor.py`) writes user-controlled and dynamic fields (like `comment`, `symbol`, `signal`, `status`) to a CSV file (`trades.csv`) without sanitization. If an attacker or external system injects a string starting with `=`, `+`, `-`, or `@` (e.g., via the MT5 comment field), opening this CSV in spreadsheet software like Excel could execute arbitrary formulas or commands.
**Learning:** Even internal logs like trade CSVs are vulnerable to formula injection when opened in spreadsheet applications, which is common for financial reporting. Blindly sanitizing *all* fields starting with `-` or `+` is dangerous in financial apps as it can corrupt legitimate numerical data (e.g., negative PnL like `-150.50`).
**Prevention:** Implement a custom CSV sanitization function that prepends a single quote (`'`) to strings starting with formula trigger characters (`=`, `+`, `-`, `@`), but explicitly skip sanitization if the string can be parsed as a valid float, ensuring numeric data remains intact.
